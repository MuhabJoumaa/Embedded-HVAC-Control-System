# Embedded HVAC Control System

An embedded control system for HVAC equipment that collects sensor data and controls valves based on the temperature set by the user through the display.

## System Architecture

The system consists of two main components:

- **Indicator:** Contains the main control logic, processes sensor data, and determines the required control actions based on operating conditions and the target temperature.
- **Power:** Handles the power-related functions and relies on the control logic provided by the Indicator component.

## Technologies

- C
- Assembly
- PIC18F45K22 microcontroller
- IDE / Development Environment: MPLAB IDE
- Embedded systems programming
- Sensor interfacing and hardware-level control
